06 · Product-company interview practice

QuestionExpected answer
Who initiates a request?Client.
Can one server handle multiple users?Yes, using concurrency, threads and asynchronous processing.
What if the only backend server crashes?Requests fail or time out; service can become unavailable.
What is SPOF?A critical single component whose failure makes a service unavailable.
How to reduce backend SPOF?Multiple instances, health checks and load-balancer-based failover.
Does client normally access DB directly?No. Client communicates with backend; backend accesses database.

60-second interview answer

“Client–Server Architecture is a model where a client, such as a browser or mobile app, sends a request to a backend server. The server processes the request, interacts with a database when required, and returns a response. One server can handle multiple requests, but its capacity is limited. If a single backend server is the only instance and it fails, the service can become unavailable — this is a Single Point of Failure. We can reduce this risk with multiple backend instances, health checks and load-balancer-based failover.”
Quick interview check

A user opens Amazon and searches for an iPhone. Who initiates the first request?
